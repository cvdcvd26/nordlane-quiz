NORDLANE QUIZ — ИСПРАВЛЕНИЯ И ПРОВЕРКИ
17 октября 2026 года

Исправлены подтверждённые ошибки из первоначального аудита и дополнительные проблемы, найденные при проверке кода и запуске. Полное отсутствие любых ошибок в любых условиях не гарантируется: реальные облачные интеграции и нагрузка проверяются после размещения.

ИСПРАВЛЕНИЯ

Чат
- Ответ менеджера больше не пропускается, когда посетитель отправил своё сообщение между опросами. Курсор получения меняется только по страницам полученных сообщений.
- Вместо времени используется последовательный номер сообщения. Это исключает пропуски из-за одинаковых или округлённых временных меток. Запись сообщений сериализуется блокировкой сессии.
- Обе стороны показывают последние 100 сообщений и могут загрузить раннюю историю. Переписка больше не обрезается первыми 500 сообщениями.
- Длинная очередь новых сообщений дочитывается страницами до конца; отправленное сообщение извлекается точно по своей записи.
- Добавление ранних сообщений не перематывает чат автоматически вниз.
- Повторная отправка ответа из админки после сетевой ошибки повторно использует ключ операции. Изменение текста создаёт новый ключ.
- Смена карточки лида сбрасывает старые черновики, историю и состояние запросов. Устаревший ответ фоновой загрузки не перезаписывает новый.
- Серверные ошибки опроса видны как отсутствие соединения; одновременные опросы исключены. Подтверждённые сообщения не дублируются среди локальных ожидающих.
- Некорректные курсоры возвращают ошибку проверки данных вместо внутренней ошибки сервера.

Задания, контакты и файлы
- Загрузка, отправка задания и удаление черновика используют общую блокировку сессии. Параллельные загрузки не превышают лимит; удаляемый файл нельзя одновременно прикрепить к заданию или сообщению.
- При отклонении загрузки метаданных уже записанный объект удаляется из хранилища.
- Удаление лида сначала блокирует его сессию и получает актуальный список файлов: конкурентная загрузка не оставляет невидимый файл после удаления лида.
- Удалённые вложения чата удаляются также на сервере. Администратор может удалять свои черновики; посетитель не может удалить черновик администратора.
- Для незавершённых вложений чата введён лимит. Удаление во время загрузки дождётся идентификатора файла и удалит его после завершения.
- Кнопки ответа на вопросы блокируются до сохранения, что исключает изменение ответов из-за неправильного порядка сетевых ответов. Автоматический переход не запускается по несохранённым данным.
- Имя из контактного шага обновляется в общем состоянии и корректно подставляется в итоговую форму отзыва.
- Номер телефона проверяется без незаметного обрезания лишних цифр. Неполный международный номер, другой код страны и буквы отклоняются; неверная вставка сохраняется в поле как ошибка, а не превращается в другой номер.
- Некорректные UUID файлов возвращают 404, а не ошибку PostgreSQL.
- Ограничивается фактический размер потока JSON и multipart, в том числе без Content-Length. Проверка MIME и сигнатуры файлов сохранена.
- Конфигурация лимитов загрузки проверяется; нельзя случайно отключить её отрицательным, бесконечным или слишком большим значением.

Автоматические сообщения и отзывы
- Проверка задания, вставка системного сообщения и отметка об отправке выполняются атомарно. Аварийное завершение откатывает операцию.
- Резервная обработка подбирает просроченные блокировки sending; свежую блокировку не перехватывает.
- Слишком ранний callback очереди получает 503 для повторной попытки, вместо подтверждения необработанного задания.
- Приглашение оставить отзыв и открытие формы записываются одной транзакцией. При ошибке можно безопасно повторить операцию.
- Адрес callback для Vercel Preview выбирается из адреса preview, а не production. Для обычного production-сервера с QStash требуется явный APP_URL.

Авторизация и запуск
- Проверка происхождения запроса учитывает протокол и Sec-Fetch-Site, а не только имя хоста.
- Посетительская сессия ограничена по возрасту также на сервере. Создание новых сессий ограничено по IP.
- Новый пароль ограничен 72 байтами UTF-8 — пределом bcrypt. Смена пароля сериализована и атомарно увеличивает версию сессии.
- CLI создания администратора проверяет email и длину пароля.
- Уведомления админки не обрезают пакет до 20 событий; сообщения различаются по ID. Убраны пересекающиеся опросы, набор просмотренных уведомлений очищается.
- Обычный удалённый PostgreSQL использует pg, Neon — WebSocket-драйвер. Добавлены явный выбор драйвера и WebSocket fallback для Node.
- CLI загружает .env.local/.env. Добавлен отсутствовавший .env.example, Node 24 в .nvmrc и корректная команда генерации типов перед TypeScript.
- В production вне Vercel локальные файлы требуют явно настроенного постоянного UPLOAD_DIR. Runtime-каталог файлов исключён из статической трассировки сборки.
- Vitest-конфигурация переведена в .mts без предупреждения о загрузке ESM как CommonJS.
